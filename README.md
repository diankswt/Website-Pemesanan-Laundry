# 🧺 Laundry Management System — Kelompok 8

Aplikasi **Laundry Management System** merupakan aplikasi berbasis web untuk membantu pengelolaan operasional usaha laundry. Aplikasi ini menyediakan fitur pengaturan data karyawan, pengelolaan pelanggan, transaksi laundry, dan laporan untuk mempermudah proses administrasi.

## 📌 Fitur Aplikasi

### 🏠 Dashboard
- Menampilkan halaman utama aplikasi.
- Menyediakan navigasi ke menu pengaturan, transaksi, dan laporan.
- Menampilkan informasi pengguna yang sedang login.

### 👨‍💼 Pengaturan Karyawan
- Menampilkan daftar data karyawan.
- Menambahkan dan mengelola informasi karyawan.
- Mengelola nama, nomor telepon, alamat, jenis kelamin, dan status karyawan.
- Menambahkan foto karyawan.
- Menyediakan fitur pencarian data karyawan.

### 👥 Pengaturan Pelanggan
- Menampilkan daftar data pelanggan.
- Menambahkan dan mengelola informasi pelanggan.
- Mengelola nama, nomor telepon, alamat, jenis kelamin, dan foto pelanggan.
- Memudahkan pengelolaan data pelanggan laundry.

### 🧾 Transaksi
- Menyediakan menu untuk pengelolaan transaksi laundry.

### 📊 Reports
- Menyediakan menu laporan untuk mendukung pemantauan data operasional laundry.
